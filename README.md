# Yake Power Systems - Sistema Web para la Gestión y Generación de Conduces

Proyecto desarrollado para la asignatura **Desarrollo de Aplicaciones Web (ISW-306)** de la Universidad Abierta Para Adultos (UAPA).

## Descripción del proyecto

Yake Power Systems es una aplicación web para la gestión y generación de conduces. El sistema permite autenticar usuarios, mantener sesiones activas, proteger páginas privadas y realizar operaciones CRUD sobre los conduces.

En la Fase 4 el proyecto fue reorganizado utilizando **CodeIgniter 4**, con el objetivo de aplicar una estructura profesional basada en rutas, controladores, modelos y vistas.

## Tecnologías utilizadas

- PHP 8.2.12
- CodeIgniter 4.7.5
- MariaDB / MySQL
- XAMPP
- Apache
- Composer 2.10.3
- HTML5
- CSS3
- Git
- GitHub

## Requisitos previos

Antes de ejecutar el proyecto se debe tener instalado:

- XAMPP con Apache, MySQL y PHP 8.2 o superior.
- Composer.
- Git.
- Navegador web actualizado.
