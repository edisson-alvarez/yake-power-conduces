Bienvenido al Sistema de Conduces

Este sistema web tiene como propósito facilitar la gestión y elaboración de los conduces utilizados por Yake Power Systems.

Durante el desarrollo del proyecto se incorporarán herramientas que permitirán registrar los datos del cliente, organizar los productos incluidos en cada entrega y generar los documentos correspondientes de una manera más eficiente.

Funciones principales

  • Registrar información del cliente.
  • Registrar los productos incluidos en el conduce.
  • Organizar la información relacionada con el despacho.
  • Preparar los datos necesarios para la generación del conduce.
