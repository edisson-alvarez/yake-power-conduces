Bienvenido al Sistema de Gestion de Conduces

Este sistema web está diseñado para facilitar la gestión y elaboración de conduces de Yake Power Systems, centralizando la información de clientes, productos y despachos en un solo lugar.

El sistema permite registrar los datos de los clientes, organizar los productos incluidos en cada despacho y gestionar la información necesaria para la generación de los conduces de manera rápida y organizada.

Funciones principales

  • Registrar información del cliente.
  • Registrar los productos incluidos en el conduce.
  • Organizar la información relacionada con el despacho.
  • Preparar los datos necesarios para la generación del conduce.
